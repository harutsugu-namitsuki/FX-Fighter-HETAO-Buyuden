# public-web（公開用の模擬サイト）

このフォルダだけを、丸ごと公開リポジトリにコピーする。GitHub Pages で公開し、アプリから携帯のブラウザで開く。

## 置くもの

- アプリから開く模擬サイトの HTML・CSS・JavaScript・画像（証券・保険・自行 Web など）
- アプリとの受け渡しは URL だけで行う（行きは URL の後ろにデータを付ける、帰りは `yourcampus://` で始まるリンク）

## 置かないもの

- 実在の会社名・銀行名・案件名・人名。データは架空のものだけにする
- 要件・設計・決定ログなどの社内の資料。これらは非公開リポジトリ側（このフォルダの外）に置く

## 決まり

- 公開リポジトリでは `public-web/` というフォルダの下に置かれる（URL の途中に `/public-web/` が入る）。そのため、リンクや画像・CSS・JavaScript の指定は**相対パス**で書く（`/css/a.css` のような `/` で始まる書き方は、公開すると別の場所を指して壊れる）。例: `../common/style.css`

- フォルダ名・ファイル名は半角英数字にする（日本語名は URL が文字化けした形になるため）。例: `securities/index.html`
- コピーする前に、非公開リポジトリ側で次のチェックを通す

```
python3 _tools/check_public_web.py
```

## ページの一覧（Your Campus 1.1）

| ページ | 中身 |
|---|---|
| `index.html` | 入口。3 つのサイトへの案内 |
| `securities/index.html` | ゆうやけ証券（架空）。口座開設・買付・売却・積立・NISA・電子交付書類 |
| `insurance/index.html` | こもれび生命（架空）。保険の見積・申込 |
| `bank/loan.html` | 住宅ローンの仮審査申込（アプリ内で開く） |
| `common/` | 共通の見た目（style.css）と、アプリとの受け渡し（app.js） |

どのページも、アプリから付けて渡されたデータ（URL の `#d=` の後ろ）が無いと「アプリから開いてください」と出る。
