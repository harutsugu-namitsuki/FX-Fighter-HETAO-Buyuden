# public-web（公開用の模擬サイト）

このフォルダだけを、丸ごと公開リポジトリにコピーする。GitHub Pages で公開し、アプリから携帯のブラウザで開く。

## 置くもの

- アプリから開く模擬サイトの HTML・CSS・JavaScript・画像（証券・保険・自行 Web など）
- アプリとの受け渡しは URL だけで行う（行きは URL の後ろにデータを付ける、帰りは `yourcampus://` で始まるリンク）

## 置かないもの

- 実在の会社名・銀行名・案件名・人名。データは架空のものだけにする
- 要件・設計・決定ログなどの社内の資料。これらは非公開リポジトリ側（このフォルダの外）に置く

## 決まり

- 公開リポジトリでは `public-web/` というフォルダの下に置かれる（URL の途中に `/public-web/` が入る）。そのため、リンクや画像・CSS・JavaScript の指定は**相対パス**で書く（`/css/a.css` のような `/` で始まる書き方は、公開すると別の場所を指して壊れる）。例: `../common/style.css`

- フォルダ名・ファイル名は半角英数字にする（日本語名は URL が文字化けした形になるため）。例: `securities/index.html`
- コピーする前に、非公開リポジトリ側で次のチェックを通す

```
python3 _tools/check_public_web.py
```

## フォルダの分け方（アプリの版ごと）

アプリの版ごとに `v1.2/` のようなフォルダに分ける。1.3 を作るときは `v1.3/` を新しく作り、`v1.2/` はそのまま残す。携帯に 1.2 と 1.3 が並んでいても、それぞれが自分の版のサイトを開くので壊れない（決定ログ D-032）。

- アプリ側の参照先は `app/build.gradle.kts` の `ycVersion` から自動で決まる（`.../public-web/v1.2/`）
- 版をまたいで共通にするものは置かない（共通にすると、新しい版の直しで古い版が壊れるため）
- ブラウザの保存領域に書く名前にも版を入れる（`common/app.js` の `VER`。1.2 は `yc12_used_codes`・`yc12_state_…`）。同じ端末に別の版が並んでも、使用済みの受付番号や画面の状態が混ざらない（D-044）
- `v1.1/` は 10/8 に作った並びのまま動かさない（D-039）。1.2 で直すときは `v1.2/` だけを直す
- `v2.0/` は 2.0（AI あり）向け。中身は 10/9 時点の `v1.2/` と同じで、`VER` だけ "20"（保存名 `yc20_used_codes`、戻りリンク `yourcampus20://return`）。AI の顔の画像は公開側に置かない（D-053）

## ページの一覧（Your Campus 1.2 → `v1.2/`）

| ページ | 中身 |
|---|---|
| `index.html` | 入口。版ごとのフォルダへの案内 |
| `v1.2/securities/index.html` | ゆうやけ証券（架空）。口座開設・買付・売却・積立・NISA・電子交付書類 |
| `v1.2/insurance/index.html` | こもれび生命（架空）。保険の見積・申込 |
| `v1.2/bank/loan.html` | 住宅ローンの仮審査申込（アプリ内で開く） |
| `v1.2/common/` | 共通の見た目（style.css）と、アプリとの受け渡し（app.js） |
| `v1.1/` | 1.1 向け（中身は v1.2 と同じ 10/8 時点のもの。保存名は版なしの `yc_used_codes`） |
| `v2.0/` | 2.0 向け（中身は v1.2 と同じ。`VER` = "20"） |

どのページも、アプリから付けて渡されたデータ（URL の `#d=` の後ろ）が無いと「アプリから開いてください」と出る。

## アプリとの受け渡し（1.2。1.1 も同じ）

- 行き: URL の `#d=` にお客さまのデータ（JSON を base64url にしたもの）
- 帰り（2 本立て）
  - アプリの中で開かれたとき: アプリが `window.YourCampusApp` を差し込む。サイトはお手続きが確定するたびに `YourCampusApp.apply(d)` を呼び、その 1 件をアプリに反映する（`common/app.js` の `record`）。だめなときは理由を出して画面の状態を変えない
  - 携帯のブラウザで開かれたとき: お手続きをためて、「アプリに戻る」で `yourcampus12://return?d=...` を開く（scheme は版ごとに違う。1.1 なら `yourcampus11://`、1.3 なら `yourcampus13://`）
